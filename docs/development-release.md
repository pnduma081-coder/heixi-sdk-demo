## 本地实现与验证范围

- 后端明确使用版本 0.4.0 + 固定 AK + Bearer SK，涵盖普通请求、上传、SDK 签名和回调验签密钥领取。SK 不进入公开配置、浏览器或日志。缺省底层协议仍为 0.3.0，携带 AK 但未显式选择 0.4.0 会拒绝。

- 新 API 请求固定直接生成。历史已记录的报价请求仅按原冻结快照恢复，不重新创建报价；不能辨认提交方式或缺少快照的旧请求拒绝重提。网络超时只恢复原请求号。
- 显式 0.4.0 Open API 的 400/403 与 401 分开处理；此规则不适用于旧 Open API 或 iframe 的 sdk/client 会话。兼容边界以 2026-09-24 同步记录为准。

### 实测发现并修复：本地视频预览缓冲

原 `/files/:id` 始终发送完整 200 响应，没有处理播放器的 Range 请求；真实视频预览停在缓冲状态。新增单段字节读取与 HEAD 支持：按请求返回 206、Content-Range 和实际分段长度，越界返回 416；无 Range、格式错误、多段或无法验证的 If-Range 返回完整内容，HEAD 不发送文件体。规则参考 [RFC 9110 Range Requests](https://www.rfc-editor.org/rfc/rfc9110.html#section-14)。

所有读取仍先校验会话、当前用户及文件归属，返回 private/no-store；客户端关闭连接时终止文件流。本地和公开 HTTPS 页面代理的 `bytes=0-1` 均实际返回 206、2 字节。没有改变主项目或重新提交生成任务。

新增临时文件/内存数据库 HTTP 回归，覆盖首段、尾段、开放终点、超大数字、越界、无效/多段、If-Range、HEAD、匿名请求、跨用户和用户切换保护。最终 **98 项测试、类型检查、Biome 和差异检查通过**。
