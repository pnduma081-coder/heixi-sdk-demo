## 报价、回调与消耗边界

后续验收记录保留以下结论：

- 两次真实报价各为 20 算力，分别通过拒绝和取消退出，未批准、提交或执行生成。
- SDK 曾通过正常 signing-key API 取得 credits 密钥，并对无效签名返回 401。有效签名、持久化幂等、内容冲突 409 和重启恢复由独立 SQLite 合成测试覆盖。
- 当时启用 credits 接收前已核对事件列表为空，没有重放旧事件。验收结束后平台 credits 配置恢复为 version 2、enabled=false，generation=null，宿主接收器关闭。
- 后续消耗查询结果为 total=0、returnedRows=0。这是当时的账户观察，不代表目前账户余额、配置或服务状态。

本地 credits 开关不开放生成批准、提交或后台事件同步。重试、重放和重复签名投递的去重验证也不等于真实扣费/退款验收。
