## 账户查询

在“接入设置”点击“查询商户账户”；API 调试也可选择对应示例并提交 `{}`。该查询只手动发起，不参与 `/api/session`、后台事件轮询或自动批准条件。F065 本地只读验收仍保持原限制，不因此开放账户查询或生成。

商户账户接口没有 `externalUserId`、`memberId`、`siteId` 或其他 query 参数。本地 `/api/call` 继续检查示例会话、来源与当前用户；平台请求只携带服务端 AK/SK，不透传浏览器 Cookie 或登录令牌。响应为 `no-store`。接入正式系统时，应把查询放入自己的商户管理员权限下。

无有效会员返回 `membershipActive=false`，等级、名称、到期时间均为 null；历史有效权益可能只有等级为 null。示例按 `membershipActive` 展示状态，按浏览器本地时间显示 UTC 到期时间。失败时清除页面旧快照，保留错误提示，不能当作余额为零或会员失效。预警阈值由接入商户设定。

## 价格与批准

价格结构版本与 SDK 版本分别演进。1.0 是原价格结构；2.0 视频增加含参考视频的生成单价 `referenceVideoUnitCredit`；3.0 再增加输入单价 `referenceVideoInputUnitCredit`。3.0 使用参考视频时，费用包含：

```text
向上取整的实际参考视频秒数 × referenceVideoInputUnitCredit
+ 生成秒数 × referenceVideoUnitCredit
```

实际输入秒数由服务端探测，整次权威售价冻结在 `estimatedCredits` 与 `saleItems`。宿主不接受浏览器上报的时长、售价作为批准依据；缺失字段和未知价格版本不能按零费处理。此示例无需自建视频估价器，纯 API 直接生成后查询实际商户成本，SDK 保留读报价、核对归属、冻结分项、批准的路径。

模型启停同时影响 SDK/API 的公开模型准入。目录可读取、素材可上传，不保证当前报价或生成仍被允许。明确拒绝后应重新读取当前模型及参数，修改生成参数须使用新请求号；受理结果未确定时先查询原请求，避免重复生成。

## 回调与结果

SDK 新生成仍要求宿主批准及启用算力回调；纯 API 显式 0.4.0 + 匹配 AK/SK 支持不配回调，0.3.0 保留旧要求。线上 SDK 常见问题中泛称“API 新生成还需要生成结果回调”的旧表述与版本专节不同，本项目按 API 调用流程及版本专节执行，不把旧要求加到 0.4.0 纯 API。

SDK 结果在内嵌页展示和恢复，不恢复 `onResult`/`resultCursor` 订阅。需要自行归档的商户可在后端读取事件和权威结果；当前默认不会自动复制 SDK 新结果到本地作品库。

平台重试及显式重放沿用 `eventId`，不得重复结算。接收端仍按原始字节验签，按事件及售价结算标识去重，可靠保存后 ACK。平台投递重试与本项目事件收件箱的 24 小时恢复窗口是两个机制，不能互相替代或据尝试次数推算扣费次数。
