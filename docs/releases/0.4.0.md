# 黑犀 SDK / API 示例项目 v0.4.0

发布日期：2026-09-27。正式源码版本，适配黑犀 SDK/API 0.4.0。功能基线为 `57ff57382b7308431b313050bc8142033239fbea`；发布提交仅补充发布文档。

## 相比 0.3.0

- 显式使用 0.4.0 协议及同一商户的 AK/SK。支持 SDK 签名、权威报价批准、API 直接生成、模型参数、上传和可选验签回调。
- 新 API 请求直接生成；新 SDK 请求校验报价后批准，售价与平台消耗事件只记录，不要求本地用户充值、余额或预占。历史请求按原策略恢复。
- 页面按需读取会话，针对具体生成任务有界查询；平台终态后等待本地保存最多 10 分钟，支持视频 Range/HEAD 播放与用户隔离。
- 事件原文与游标原子保存，异常不挡住后续接收。格式/关联错误每轮失败 3 次后暂停；媒体/本地处理错误失败 8 次后转为每小时重试，首次接收后的 24 小时为自动恢复上限。
- 重试和未尝试事件各有独立的 10 秒启动预算，每轮合计最多 20 条、重试最多 10 条；按已保存的重试时间提前唤醒。已开始的保存正常收尾，不承诺整轮固定超时。
- 区分未发送、明确拒绝、结果未确认和已受理请求，重启后修正中断状态，成功响应不会被晚到失败覆盖。

## 获取与运行

使用 GitHub Release 自动提供的源码归档，或克隆稳定分支：

```bash
git clone --branch release-0.4.0 https://github.com/pnduma081-coder/heixi-sdk-demo.git
cd heixi-sdk-demo
pnpm install --frozen-lockfile --ignore-scripts
cp -n .env.example .env.local
pnpm dev
```

需要 Node.js 24+、pnpm 11。商户 AK/SK 仅填入自己的 `.env.local`，SK 不交给浏览器。API 调试可使用本机 HTTP；SDK 宿主要求登记的 HTTPS 来源。完整说明见 [README](../../README.md)。

## 升级注意

- 更新已有实例前停止新受理并备份本项目配置、数据库和媒体。不要以旧数据库覆盖已经发生的新任务或账务；回退步骤见 [开发与发布记录](../development-release.md#回退)。
- 旧收件箱中没有可信恢复期限的未完成项会暂停，不自动重新跑历史记录。原文保留，核对后可手动恢复；手动“重试待处理及暂停事件”会作用于当前用户的未完成项。已完成记录不重新排队。
- 0.4.0 SDK 内嵌页自行展示结果，不再依赖宿主 `onResult`；`release-0.3.0` 保留旧源码，不保证旧回调归档方式在新内嵌页上继续生效。
- 本项目是商户接入示例，不提供生产登录、支付或终端用户钱包。商户正式接入时替换示例身份切换与业务策略。
